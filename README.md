# 數字火車｜課堂抽號器 Pro

純 HTML / CSS / JavaScript，不需安裝套件，可直接部署到 GitHub Pages。

## 功能
- 原版 40 張牌庫邏輯
- 一次抽 1～5 張
- 每回合決策倒數
- 整局預估時間
- 實際遊戲計時
- 可設定整局時間目標
- 暫停 / 繼續
- 倒數結束提示音
- 可選擇倒數結束自動抽下一批
- 課堂投影大字模式
- 本局抽牌歷史
- 下載抽牌紀錄 TXT
- 手機 / 平板 / 電腦響應式版面

## GitHub Pages
1. 建立新的 Repository
2. 將 `index.html` 與 `README.md` 上傳到根目錄
3. Settings → Pages
4. Source 選 `Deploy from a branch`
5. Branch 選 `main` / `(root)`
6. 儲存後等待 GitHub 產生公開網址
